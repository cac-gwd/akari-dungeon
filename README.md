# 灯の迷宮

一歩進めば、迷宮も動き出す。地下10階に眠る「帰り灯」を持ち帰る、ターン制ローグライクゲームです。

iPhoneの縦画面・タッチ操作に対応。毎回変わる迷宮で、道具と食料をやりくりしながら探索します。

## ゲームを遊ぶ

**[灯の迷宮をプレイする](https://cac-gwd.github.io/akari-dungeon/)**

上のリンクから、そのままブラウザで遊べます。アカウント登録は不要です。

## バージョン

現在の公開版は **v1.1.3** です。タイトル横・ゲーム画面下部と「?」に、実際に起動している版を表示します。v1.1.3には道具の「置く・交換」と足元の道具表示が含まれます。

番号が表示されない場合は、[更新専用ページ](https://cac-gwd.github.io/akari-dungeon/update.html)で「最新版を取得して開く」を押してください。更新ページはセーブデータを削除しません。Safariとホーム画面アプリで保存領域が分かれている場合は、それぞれで更新が必要です。

## 遊び方

- **移動・攻撃**：方向ボタンで8方向に移動。敵の方向に進むと攻撃します。地図のタップやスワイプでも操作できます。
- **ターン制**：操作するまで敵は動きません。「待つ」と道具の使用でも一手進みます。
- **道具**：癒やし草で回復、おにぎりで食事。雷の札や風の石で危機を切り抜けます。刀と護符は拾うと自動で強化されます。
- **置く・交換**：道具袋で選んだ道具を足元に置けます。足元に道具がある場合は「交換」で入れ替えます。袋がいっぱいでも交換でき、どちらも一手進みます。置いた道具はその場に残り、再び踏むか「待つ」で拾えます。
- **満腹度**：4手ごとに1減り、0になると毎手ダメージを受けます。空腹でなければ6手ごとに生命が1回復します。
- **階段**：階段の上に立ち、「階段を降りる」で次の階へ。地下10階で「灯を持ち帰る」とクリアです。
- **冒険の終わり**：倒れると、その冒険の道具と成長を失います。最高到達階と帰還記録は残ります。

詳しい操作はゲーム内の「?」から確認できます。PCでは矢印キーまたはHJKLで移動、YUBNで斜め移動、Spaceで待機できます。

## iPhoneのホーム画面に追加

1. [ゲーム](https://cac-gwd.github.io/akari-dungeon/)をSafariで開きます。
2. 共有メニューから「ホーム画面に追加」を選びます。
3. 追加したアイコンからオンラインで一度起動し、画面下部の「オフライン準備完了」を確認します。

ホーム画面からは独立したアプリ画面で起動する設定です。準備が完了すれば、通信なしでも遊べます。初回アクセスには通信が必要です。

## セーブについて

冒険は一手ごとに端末内へ自動保存されます。ゲーム内の「?」からセーブの書き出し・読み込みもできます。

ブラウザのデータを削除するとセーブも消えるため、残したい冒険は書き出してください。端末間の自動同期や、複数タブでの同時プレイには対応していません。Safariとホーム画面アプリで続きが共有されない場合は、セーブファイルで移せます。

## 開発について

HTML・CSS・JavaScriptで実装した静的PWAです。外部ライブラリや外部配信アセットへの依存はなく、GitHub Pagesで公開しています。既存作品のキャラクター・画像・音楽は使用していません。

### ローカルで動かす

Node.jsを用意し、このリポジトリで実行します。

```sh
npm start
```

ブラウザで `http://127.0.0.1:4173` を開きます。`file://` で直接HTMLを開く方法には対応していません。

### テスト

```sh
npm test
```

迷宮100個の連結性、配置、セーブ、戦闘、ターン進行、道具、死亡・クリアと、PWAのキャッシュ対象を検証します。iPhone実機でのインストール・機内モード動作は未検証です。

### ゲームを更新する場合

キャッシュ対象のゲームファイルを変更したら、`app.js` の `VERSION`、`package.json` の `version`、`sw.js` のキャッシュバージョン、READMEの公開版番号をそろえて上げて公開します。開いているゲームをすべて閉じて起動し直すと、新しいバージョンに切り替わります。READMEのみの変更では、キャッシュの更新は不要です。
