# 灯の迷宮

iPhoneの縦画面とタッチ操作を前提にした、小さなターン制ローグライクです。既存作品のキャラクター・画像・音楽は使用していません。依存ライブラリや外部配信アセットなし、ビルド不要の静的サイトです。

## GitHub Pagesで公開する

1. GitHubでリポジトリを作成します。
2. **このフォルダの中身**をリポジトリのルートに入れます。`index.html` が最上位になるようにします。`.nojekyll` も含めてください。
3. リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch** を選びます。
4. **main / (root)** を選び、Saveします。
5. 公開が完了したら表示された `https://ユーザー名.github.io/リポジトリ名/` を開きます。

HTML・manifest・Service Workerの参照は相対パスです。リポジトリ名のサブパスでも動作します。公開URL: https://cac-gwd.github.io/akari-dungeon/

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## iPhoneに追加する

1. 公開URLをSafariで開きます。
2. 画面下部の「オフライン準備完了」を確認します。
3. 共有メニュー →「ホーム画面に追加」。iOSで「Webアプリとして開く」が表示される場合は有効にします。
4. ホーム画面のアイコンから起動します。`display: standalone`、Apple用メタタグと180pxアイコンを設定しています。
5. ホーム画面からの初回起動時もオンラインで開き、「オフライン準備完了」を確認してください。その後は機内モードでも遊べます。

初回アクセスには通信が必要です。iOSの実機でのインストール・機内モード動作は、公開後に確認してください。端末やOSのデータ削除で保存やキャッシュが失われる場合があります。

WebKit資料: https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/

## 遊び方

- 地下10階の階段位置にある「帰り灯」を持ち帰るとクリア。
- 方向キーで8方向に移動。敵の方向へ動くと近接攻撃。壁の角を斜めには抜けられません。
- 画面上の方向ボタンのほか、地図のタップ・スワイプに対応。全体図では誤操作を防ぐため地図操作は無効です。
- 操作するまで敵は動きません。「待つ」と道具使用も1ターン消費します。
- 4ターンごとに満腹度が1減り、0になると毎ターン生命が1減ります。空腹でなければ6ターンごとに生命が1回復します。
- 草・おにぎり・雷の札・風の石で切り抜けます。刀と護符は拾うと自動で強化。道具袋は12個まで。
- 雷は壁を越えて周囲6マスに届きます。風の石は敵から離れた床へ移動します。
- 罠は踏むまで見えません。一度発見した罠も再び踏むと発動します。
- 死亡でその冒険の成長・道具を失います。最高到達階と帰還記録は残ります。
- PC: 矢印 / HJKL、斜め YUBN、Spaceで待機。

## 保存

一手ごととバックグラウンド移行時にlocalStorageへ自動保存します。アカウント・サーバー・通信による保存はありません。同じ公開URL・同じブラウザの端末内保存で、複数タブでの同時プレイには対応しません。Safariとホーム画面アプリ間で保存領域が異なる場合は「? → セーブを書き出す / 読み込む」で冒険を移せます。読込は冒険のみを置き換え、移行先の最高到達階・帰還記録は維持します。

## ローカル確認

Node.jsを用意して、このフォルダで以下を実行します。

```sh
npm start
```

`http://127.0.0.1:4173` を開きます。直接ファイルを開く `file://` ではES ModulesやService Workerが動作しないため使わないでください。Service WorkerはHTTPSまたはlocalhost系で動作します。

```sh
npm test
```

ダンジョン100個の連結性、配置重複、セーブ往復、戦闘、ターン進行、空腹、道具、死亡・クリアを確認します。

## 更新

ファイル変更時は `sw.js` の `CACHE` のバージョン（`v2`）を上げてから公開します。新しいキャッシュは全ファイルの取得完了後に有効になります。開いているゲームをすべて閉じて起動し直すと新バージョンへ切り替わります。セーブキーのバージョンは別管理で、更新の際に不用意に変更しないでください。

## ファイル

- `index.html` / `style.css`: 縦画面UI
- `engine.js`: 迷宮生成・戦闘・ゲームルール
- `app.js`: 描画・操作・保存
- `sw.js`: アプリ一式のオフラインキャッシュ
- `manifest.webmanifest` / `icons/`: PWA設定とアイコン
- `server.js`: ローカル確認用サーバー（本番には不要）

## 実機での最終確認

- Safariで開く → ホーム画面に追加 → アドレスバーなしで起動
- オフライン準備完了後、機内モードで閉じて再起動
- 数手進めて閉じる → 同じ階・生命・位置から再開
- ノッチとホームインジケータ、文字サイズ設定でボタンが押せること

画面の余白にはsafe-areaを使用しています。manifestの縦方向指定をOSが適用しない場合も、ゲーム画面自体は縦長の幅に収まります。
